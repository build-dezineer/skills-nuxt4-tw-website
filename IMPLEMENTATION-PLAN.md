Status: **complete** (2026-10-01). All 28 skills pass `skills-ref`, the repository
checks, and the index check; evals added for `hero` and `navigation`.
Scope: **W1** of [`SkillsPublishingPlan.md`](../sgs-design/SkillsPublishingPlan.md)
(sgs-design), applied to this repository (the plan's `dezineer-skills-website`, 28

## Goal

Package Dezineer's website designer skills as first-class, standard Agent Skills
(agentskills.io): spec-only frontmatter, `skills/<name>/SKILL.md` layout, generated
`skills/index.json`, CI validation, README/CONTRIBUTING, evals for the objectively
verifiable skills.

## Skill file contract

Frontmatter (only these keys):

```yaml
---
name: hero                        # must equal the folder name
description: >-                   # ≤1024; what it builds + "Use when …" + flavor coverage
  Complete hero / above-the-fold section … Use when building the hero … Covers
  fullscreen, split, stacked and typographic layouts.
license: Apache-2.0
compatibility: >-                 # ≤500
  Requires a Dezineer-scaffolded Nuxt 4 project (Tailwind v4 design tokens,
  shared components, media pipeline). Guidance targets Dezineer's generator;
  patterns may transfer to a plain Nuxt project with those primitives.
metadata:
  version: "1.0.0"
  tags: "layout, hero, above-the-fold"
  stack: "nuxt4, vue3, tailwind4, radix-vue, gsap"
---
```

- `compatibility` is the human/agent-readable sentence; `metadata.stack` is its
  machine twin (comma-separated tokens, Appendix F vocabulary).
- Body rules: keep existing instructions; `SKILL.md` under 500 lines (spec
  recommendation); move detail to `references/` with **when-to-load** guidance, one
  level deep; cross-skill references become relative links (`../media/SKILL.md`); no
  Dezineer-internal jargon where a generic phrasing works.
- Versioning: start at `1.0.0`; content edits bump patch/minor; an input/section
  contract change bumps major. Repo tags (`v1.0.0`) pin snapshots.

## Index format

```json
{ "skills": [
  { "name": "hero", "files": ["SKILL.md", "references/variants.md"], "version": "1.0.0" }
] }
```

Files are sorted, resolved relative to `<index-dir>/<name>/`. Evals and assets are
part of the skill and are listed.

## Steps

1. **Skeleton** — `LICENSE` (Apache-2.0), `README.md`, `CONTRIBUTING.md`,
   `.gitignore`, `package.json` (private; `js-yaml` devDependency; `validate`,
   `validate:spec`, `index`, `index:check` scripts).
2. **Import** — copy the 28 skill directories from
   `sgs-design/templates/nuxt-website/skills/` (exclude `manifest.json`);
   `3d-scene`: move `ThreeScene.vue` and `usePostFX.ts` into `assets/` and update
   body links.
3. **Frontmatter pass (28 files)** — `name` = folder; authored `description`
   (Appendix D formula, target 250–500 chars) from manifest summaries + bodies;
   `license: Apache-2.0`; standard `compatibility`; `metadata.version: "1.0.0"`;
   `metadata.tags` from the old manifest; `metadata.stack` from Appendix F based on
   actual imports.
4. **Body rework** — split `navigation` (859 lines) into
   `references/variants.md` + `references/overlay.md` with when-to-load guidance;
   convert cross-skill mentions to relative links (`media`, `marquee`, `hero`,
   `3d-scene`, commerce skills); audit internal paths.
5. **Tooling** — `scripts/build-index.mjs` (walk `skills/*/`, parse frontmatter,
   validate name=dir + version, sorted file list, `--check` mode);
   `scripts/validate-skills.mjs` (unique names, description caps, spec-only keys,
   `dezineer-*` forbidden, indexed files exist, relative links resolve, no
   `scripts/` dir).
6. **CI** — `.github/workflows/validate.yml`: Node 20 + `astral-sh/setup-uv`;
   `npm ci`; `uvx --from skills-ref agentskills validate` per skill;
   `node scripts/build-index.mjs --check`; `node scripts/validate-skills.mjs`.
7. **Evals** — `skills/hero/evals/evals.json` and
   `skills/navigation/evals/evals.json` (2–3 realistic prompts, `expected_output`,
   optional `files`/`assertions`); README documents how to run them.
8. **Verification** — validator clean, index fresh, links resolve, no host keys;
   report.
